# Shopify Foundation

Prompt 7 adds Shopify read/import foundations: OAuth connect, strict `*.myshopify.com` validation, HMAC verification, encrypted token storage, GraphQL Admin API product sync, webhook delivery idempotency and UI under `/app/integrations/shopify`.

Write/apply is intentionally disabled. Rankelia does not publish Shopify changes yet; approved proposal application belongs to Prompt 8 change sets and rollback.
