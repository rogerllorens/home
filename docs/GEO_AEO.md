# GEO/AEO Readiness

GEO/AEO estimates whether a page is easy for search engines and conversational AI systems to understand, summarize and cite. It does not guarantee AI Overviews, ChatGPT, Gemini, Perplexity or rankings.

## Criteria

- Entity clarity: brand, category, product/service and language signals.
- Answer readiness: clear title, H1, meta description and direct introductory content.
- Content structure: useful H2s, links, FAQs and scannable sections.
- Schema support: Organization, WebSite, Product, FAQ and Breadcrumb when appropriate.
- Trust/safety: no fake reviews, exaggerated claims or unverifiable promises.

## Improvements

Add clear sections, visible FAQs, truthful product/category data, schema that matches visible content and concise answer-style paragraphs.
